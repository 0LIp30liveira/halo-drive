Política de Privacidade — Halo Drive Downloader

Última atualização: 2 de novembro de 2026.

Quais dados acessamos

Com a autorização do usuário, o aplicativo acessa o Google Drive com permissão somente de leitura (drive.readonly) para listar e baixar as pastas e arquivos que o próprio usuário indicar.

Como usamos

Os arquivos são copiados apenas para o computador do usuário. Nenhum dado é enviado para servidores da agência ou de terceiros, armazenado em nuvem, vendido ou compartilhado.

Armazenamento do acesso

O token de acesso do Google fica salvo somente no computador do usuário. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
